# Rumble

DIY Acousto-Haptic SubPac — real-time system audio to haptic bass feedback via game controllers.

## Concept

Capture PC system audio (WASAPI Loopback), split it by frequency, and route it to game controller motors for physical bass feedback on a chair or body mount.

- **Xbox Controller (ERM motors):** Sub-bass sustain (<60 Hz) — slow, heavy rumble for 808s and basslines
- **PS5 DualSense (LRA actuators):** Transients/punches (70-140 Hz) — fast, precise hits for kicks and snares
